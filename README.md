# node_boiler_plate
A MERN stack boilerplate created using MiMo V2.5 Free model and OpenCode cli

## Getting Started

```bash
# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Start development server
npm run dev

# Start production server
npm start
```

## Scripts

- `npm start` - Start the server
- `npm run dev` - Start with file watching (Node 18+)
- `npm test` - Run tests
- `npm run lint` - Run linter

## Project Structure

